# Agent rules

This repository is public. Customer and target projects that auto-bumper is run against must stay anonymous.

- Never put customer or target project names, repo names, hostnames, org names, or machine paths into tracked files, docs, tests, the changelog, or commit messages.
- Call them "a consumer project". Public CVE ids, package coordinates, and versions are fine.
- `llm-wiki/` may hold private run notes. Do not copy names from there into the repo.
